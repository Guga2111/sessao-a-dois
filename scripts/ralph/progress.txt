## Codebase Patterns
- No JDK 21 / Maven Central in this sandbox: `java` is absent and `./mvnw` cannot download Maven. Backend build/test (`./mvnw test`) can only be verified on a machine with JDK 21 + Maven Central access. Make correct changes and note verification is deferred.
- Base Java package is `com.app`; Maven `groupId` stays `com.lf` (intentional). See api/CLAUDE.md.
- Test `src/test/resources/application.properties` REPLACES the main one for `@SpringBootTest` — redeclare every required property (`tmdb.api-key`, `app.jwt.secret`).
- Unit-test the shared TMDB `RestClient` with `Mockito.mock(RestClient.class, RETURNS_DEEP_STUBS)` and stub the terminal `.body(Type.class)`.
- Entities with `@GeneratedValue` ids have no id setter; use `ReflectionTestUtils.setField(entity, "id", uuid)` in unit tests.
