## Codebase Patterns
- Plain (non-base-ui) primitives like `Skeleton` follow `card.tsx`'s shape: `import * as React from "react"`, a single function component typed `React.ComponentProps<"div">`, `data-slot="..."` on the root, `cn(...)` merging default classes with `className`. No CVA needed unless there are real variants.
- Theme is dark-prototype-driven: cards use `bg-[#161513]`, `border-[rgba(255,255,255,.07)]`, `rounded-[18px]`; inner placeholder/skeleton blocks use `bg-white/[0.06]`. Source of truth is `docs/design/claude-design-project/Sessao a Dois.dc.html`.
- `tsc --noEmit` and `npx eslint <file>` both run cleanly from `client/` with no extra flags needed for quick per-file checks.
