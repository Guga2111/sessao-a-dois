## Codebase Patterns
- Backend Java lives in `api/` (Spring Boot, Maven wrapper `./mvnw`). Base Java package is `com.app` (NOT the Maven groupId, which stays `com.lf`).
- Spring Boot parent version is 4.1.0 with Java 21 (see api/pom.xml).
- Package-by-feature is the target architecture: com.app.user, com.app.couple, com.app.media, com.app.tracking, com.app.match, com.app.security, com.app.websocket (see docs/ARCHITECTURE.md).
- ENV CONSTRAINT: This Ralph runtime has NO JDK/Maven installed and only `github.com` is on the network allowlist (Maven Central / Adoptium unreachable). Maven builds/tests CANNOT be executed here. Validate builds in an environment with JDK 21 + Maven Central access. Do static validation (XML well-formedness, package/dir structure) as a stopgap.
- CLAUDE.md mandates reading everything under `docs/` before any task, and using the `frontend-design` skill for any `client/` work.
