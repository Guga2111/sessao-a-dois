## Codebase Patterns
- ResourceNotFoundException now lives in com.app.common (moved from com.app.tracking in US-001). Any class in another package that throws/catches it must `import com.app.common.ResourceNotFoundException;` explicitly - it is no longer implicitly available within com.app.tracking either, since the package changed.
- Backend test suite: `./mvnw -o test` from `api/` (offline mode works in this sandbox). 416 tests total as of US-001. Some tests deliberately log ERROR/exception stacktraces as part of asserting error-handling behavior (e.g. MediaControllerTest's TMDB-unavailable case, MatchService.healMetadata) - that noisy output is expected and not a failure signal; check the final "Tests run: X, Failures: 0, Errors: 0" summary instead.

## 2026-08-05 - US-001
