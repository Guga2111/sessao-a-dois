## Codebase Patterns
- Backend Java lives in `api/` (Spring Boot, Maven wrapper `./mvnw`). Base Java package is `com.app` (NOT the Maven groupId, which stays `com.lf`).
- Spring Boot parent version is 4.1.0 with Java 21 (see api/pom.xml).
- Package-by-feature is the target architecture: com.app.user, com.app.couple, com.app.media, com.app.tracking, com.app.match, com.app.security, com.app.websocket (see docs/ARCHITECTURE.md).
- ENV CONSTRAINT: This Ralph runtime has NO JDK/Maven and NO Docker installed, and only `github.com` is on the network allowlist (Maven Central / Adoptium / Docker Hub / pip unreachable). Maven builds/tests, Docker builds, and `docker compose` CANNOT be executed here. Validate in an environment with JDK 21 + Docker + internet. Do static validation (XML well-formedness, YAML no-tabs/indentation, package/dir structure) as a stopgap.
- DEV DB CREDENTIALS (single source of truth): db=sessao, user=sessao, password=sessao, on localhost:5432 (see docker-compose-dev.yml). The API defaults (US-003 application.properties) MUST match these exactly: DB_URL=jdbc:postgresql://localhost:5432/sessao, DB_USER=sessao, DB_PASSWORD=sessao. PgAdmin dev UI is on host port 5050.
- CLAUDE.md mandates reading everything under `docs/` before any task, and using the `frontend-design` skill for any `client/` work. NOTE: docs/ now also has `BACKLOG.md` (the full epic/task backlog) — read it too.
- Spring Security config lives in `com.app.security.SecurityConfig` as a `@Configuration` exposing a `SecurityFilterChain` bean (Spring Security 6 lambda DSL: `.csrf(c -> c.disable())`, `.authorizeHttpRequests(a -> a.anyRequest()...)`, `.formLogin(f -> f.disable())`, `.httpBasic(b -> b.disable())`). Epico 1 uses permitAll; Epico 2 replaces it with JWT + CORS.
- Public/root endpoints (e.g. health) go directly under `com.app` as `@RestController`. `/api/health` returns `Map.of("status","UP")` (auto JSON).
