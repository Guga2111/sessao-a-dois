## 2026-07-20 - US-001
- Implemented TmdbConfig (com.app.media): RestClient @Bean (`tmdbRestClient`) reading `tmdb.base-url` (default https://api.themoviedb.org/3) and `tmdb.api-key` (env TMDB_API_KEY, no default) via constructor @Value injection.
- Fail-fast: bean throws IllegalStateException with a clear pt-BR message when the API key is blank; since Spring beans are eagerly instantiated by default, this happens at application startup.
- API key is sent via `Authorization: Bearer <key>` header (never logged, never appended to URLs/logs).
- Added `TmdbDefaultLanguageInterceptor` (ClientHttpRequestInterceptor) that injects `language=pt-BR` into every outgoing TMDB request URI (via HttpRequestWrapper), unless the caller already specified `language` explicitly.
- Added `tmdb.base-url` / `tmdb.api-key` properties to api/src/main/resources/application.properties.
- Added `api/src/test/resources/application.properties` with a fake `tmdb.api-key` so `@SpringBootTest` (SessaoADoisApplicationTests etc.) keeps booting without a real TMDB_API_KEY set.
