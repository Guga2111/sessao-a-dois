## Codebase Patterns
- Frontend-only feature (client/). No backend/endpoint changes — reuse GET /api/media/{movie|tv}/{tmdbId} (MediaDetails).
- Any code in client/ must go through the frontend-design skill before implementing (project rule in CLAUDE.md).
- Modal fetch pattern to mirror: MediaDetailModal.tsx / PendingDetailModal.tsx.
- Lint gotchas (client/CLAUDE.md): no synchronous setState directly in a useEffect body — wrap fetch-on-mount in setTimeout(..., 0) + `cancelled` flag; reset state on tab change via key={activeTab} remount of a subcomponent, not setState-in-effect.
- Comparison-mode state is local useState per screen — do NOT touch Zustand stores.
- Reads use Skeleton + useDelayedLoading, never spinners.
- shadcn/base-ui Dialog usage: pass showCloseButton={false} + roll a custom close Button with a Portuguese aria-label, and always render <DialogTitle className="sr-only"> (base-ui Dialog.Popup needs an accessible name). See TitleModal.tsx / ComparisonDialog.tsx.
